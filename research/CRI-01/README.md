# SGP-QSV · CRI-01 — 검증 회피 위험신호 지수 연구

**연구 공개안:** 2026-10-25 · **상태:** EXPERIMENTAL_RESEARCH (실증 전 연구 후보)

**설계적 연결:** CIVIC-TRACE 0.4.5 하위 연구. AX-01~AX-09 유지, 0.4.6 R3 승인 보류 유지 (2026-10-26 재검토 예정, 자동 승인 아님).

## 목적과 경계

권한·자료를 보유하는 주체가 시민의 검증 요청에 응답하는 과정에서 관찰할 수 있는 **절차적 위험신호**를 정량화하는 최초의 모형이다. 부패, 악의, 위법, 의학적 인과관계를 자동 판단하거나 개인·기관에 제재하지 않는다. 자료의 부존재와 사건의 부존재를 같게 보지 않으며 권력·정보 비대칭을 검토하되 피해자에게 추가 입증 부담을 전가하지 않는다.

## 실험적 산식

| 지표 | 기호 | 임시 가중치 |
|---|---|---:|
| 검증 자료 접근 제한 | E | 0.30 |
| 응답·처리 의무 미이행 | D | 0.20 |
| 문서 간 미해소 불일치 | C | 0.20 |
| 독립 검증 제한 | V | 0.20 |
| 정정·이의제기 채널의 한계 | R | 0.10 |

각 지표 0~1. `CRI=100*(0.30E+0.20D+0.20C+0.20V+0.10R)`.

**실증 검증되지 않은 임시 가중치이며, 0~1을 판정하는 앵커·평가자 간 신뢰도·오탐 시험은 후속 과제다.** 고득점이 부패 확정이 아니다.

## 필수 증거 상태

VERIFIED / DISPUTED / UNKNOWN / UNAVAILABLE / NOT_APPLICABLE.

단 한 지표라도 VERIFIED가 아니면 현재 프로토타입은 `score:null`을 반환한다. 미확인과 접근불가를 0점으로 대체하지 않는다. VERIFIED에는 출처 참조가 필수다. 독립적인 실사나 자료 검증을 이 코드가 수행하는 것은 아니다. 합성 시험값의 VERIFIED는 *실제 사실 검증*이 아니라 시험 형식의 입력 상태다.

## 실행

Python 3.9+ (외부 패키지 없음):

```sh
python3 cri01.py example.json
python3 -m unittest discover -s tests -v
```

`example.json`은 실제 피해자·기관과 무관한 합성 예시이며, 숫자의 합리성·법적 효력을 입증하지 않는다.

## 책임·계보

2026-10-23 GitHub 공개 기록의 CIVIC-TRACE 0.4.5 하위 승인 6건과 수동 영수증 상태를 변경하지 않는다. 0.4.6은 아직 보류이며 실서비스·대외 채택 여부는 미확인. 역사적 연구층, 승인층, 후보층을 구분하고 LP728의 의학적 인과관계 및 LOT 00518001의 정체는 미해결로 보존한다. 비공개 소송 원자료 또는 사적 대화는 포함하지 않는다.
